# Cognos Sales Performance Dashboard

## Project Overview

This project presents an interactive sales dashboard created using IBM Cognos Analytics to analyze sales performance and business metrics.

## Dashboard Features

- Sales Performance
- Profit Analysis
- Quantity Sold
- Dealer Performance
- Interactive Visualizations

## Tools Used

- IBM Cognos Analytics
- Microsoft Excel

## Skills Demonstrated

- Dashboard Design
- KPI Reporting
- Business Intelligence
- Data Visualization
